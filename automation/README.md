# Googleフォームからの自動投稿セットアップ

スタッフがGoogleフォームに投稿すると、自動でこのサイト(`data/materials.json`)に
追加され、GitHub Pagesへ公開されます。GitHubのアクセストークンを個人で用意する
必要はなく、フォームに入力するだけで投稿できます。

## 全体の流れ

```
Googleフォーム回答(資料・動画ファイルを直接アップロード)
   → 連携するGoogleスプレッドシートに自動で行が追加される
   → スプレッドシートの Apps Script が「フォーム送信時」に自動起動
   → アップロードされたファイルの共有設定を「リンクを知っている全員が閲覧可」に変更
   → そのファイルへの共有リンクを data/materials.json に追加(GitHub API経由)
   → GitHub Pages が自動で再デプロイ
```

資料・動画の実体ファイルはGitHubにはコピーせず、アップロード先のGoogleドライブに
そのまま置かれます(動画は容量が大きくGitHubに向かないため)。サイト側は
既存のGoogle Drive埋め込み表示の仕組みでそのまま再生・プレビューします。

## 1. GitHubのアクセストークンを発行する

1. GitHubで自分のアイコン → **Settings → Developer settings → Personal access tokens
   → Fine-grained tokens** を開く
2. **Generate new token**
   - Repository access: **Only select repositories** → `tanpopo-seminar`(このリポジトリ)を選択
   - Permissions → **Contents** を **Read and write** に設定
   - 有効期限はお好みで(更新の手間を減らすなら長め、セキュリティ重視なら短め)
3. 発行されたトークン(`github_pat_...`)をコピーしておく
   (**このページを閉じると二度と表示されません**。安全な場所に一時保存してください)

## 2. Googleフォームを作る

以下の質問を作成する。質問文は**前方一致**で判定しているので、説明文を
括弧書きで付け足すなど多少の言い回しの変更をしても問題ない(例:「タグ」
→「タグ(検索しやすくするために…)」でもOK)。ただし「資料ファイル」で
始まる質問が2つあるので、動画用の質問には**必ず「動画」という文字**を
含めること(下記の表記を参考にしてください)。

| 質問 | 種類 | 必須 |
|---|---|---|
| タイトル | 記述式 | ✅ |
| 実施日 | 日付 | 任意 |
| 登壇者・講師 | 記述式 | 任意 |
| カテゴリ | プルダウン(下記の8種類) | ✅ |
| タグ | 記述式(カンマ区切りで複数可) | 任意 |
| 概要 | 段落 | 任意 |
| 投稿者 | 記述式 | 任意(サイトに【投稿者:○○】と表示されます) |
| 資料ファイル(写真やPDF) | ファイルのアップロード(複数可) | 任意 |
| 資料ファイル(動画) | ファイルのアップロード(**1個までに設定**) | 任意 |

「資料ファイル(写真やPDF)」は複数枚まとめてアップロードでき、サイトの
詳細画面で前へ/次へとめくって見られます。「資料ファイル(動画)」は
質問の設定で**アップロード数の上限を1個**にしてください(スクリプトは
複数アップロードされても先頭の1件しか使いません)。

カテゴリのプルダウンの選択肢(サイトの絞り込みタブと合わせる):

```
小出セミナー
秋葉塾
その他入力関連
インプラント
その他歯科治療関連
DH関連
口腔機能関連
その他
```

「資料ファイル(写真やPDF)」に写真(画像ファイル)をアップロードした場合は、
Googleドライブの汎用プレビュー(ズームアイコンなどが出て見づらい)ではなく、
サイト側で画像そのものを大きくきれいに表示するよう自動で判定しています。

「ファイルのアップロード」の質問は、フォームの設定で回答者がGoogleアカウントで
ログインしている必要がある旨が表示されます(院内のGoogleアカウントで運用する
分には問題ありません)。アップロードされたファイルは、Googleフォームの仕様上
フォーム所有者のGoogleドライブ内に「(フォーム名) (ファイルの回答)」という
フォルダが自動生成され、その中に保存されます。定期的に整理したい場合は、
このフォルダの中身を専用フォルダへ移動しても、サイト側の共有リンクは
変わらないので問題ありません(共有ドライブへ移動する場合はリンクを再取得
してください)。

## 3. スプレッドシートと連携する

フォームの「回答」タブ → 緑色のスプレッドシートアイコン →
「新しいスプレッドシートを作成」で連携する。

## 4. Apps Scriptを設定する

1. 連携したスプレッドシートを開く → メニューの **拡張機能 → Apps Script**
2. デフォルトの `Code.gs` の中身を全部消して、このリポジトリの
   `automation/google-form-to-github.gs` の中身を貼り付ける
3. 左側の歯車アイコン「プロジェクトの設定」→ 一番下「スクリプト プロパティ」で
   以下を追加する(**コードには直接書かない**)

   | プロパティ | 値 |
   |---|---|
   | `GITHUB_TOKEN` | 手順1で発行したトークン |
   | `REPO_OWNER` | `andominami` |
   | `REPO_NAME` | `tanpopo-seminar` |

4. 上部の「時計」アイコン(トリガー)→ **トリガーを追加**
   - 実行する関数: `onFormSubmit`
   - イベントのソース: `スプレッドシートから`
   - イベントの種類: `フォーム送信時`
   - 保存時にGoogleアカウントの権限承認を求められるので許可する
     (Googleドライブの共有設定を変更する必要があるため、Driveへのアクセス許可も
     求められます。院内利用の範囲であれば許可して問題ありません)

## 5. テストする

実際にフォームから1件テスト投稿してみて、数分後に
https://andominami.github.io/tanpopo-seminar/ に反映されているか確認する。

うまく反映されない場合は、Apps Scriptエディタの左側「実行数」から
エラーログを確認できます(GitHubトークンの権限不足、質問名の表記ゆれ、
アップロードファイルの共有設定失敗などがよくある原因です)。

## 資料の削除・修正について

Googleフォームは「追加」専用の仕組みです。登録済みの資料を削除・修正したい
場合は、このリポジトリを操作しているClaudeのチャットに頼んでください。
GitHubの操作に慣れている場合は `data/materials.json` を直接編集しても
構いません。
