1. GitHub トークンの設定

このページはあなたのブラウザから GitHub API を直接呼び出して、リポジトリにコミットします。 Fine-grained personal access token（対象リポジトリのみ・Contents: Read and write 権限のみ）を発行して入力してください。 トークンはこの端末のブラウザ内（localStorage）にのみ保存されます。共有パソコンでは保存せず、使い終わったら削除してください。

2. 新しい資料を登録

Google Drive のリンクは「リンクを知っている全員が閲覧可」の共有設定にしてください。サムネイル画像・プレビュー再生に使われます。
