資料の登録・管理

ここで登録した内容は GitHub リポジトリに直接コミットされ、サイトに反映されます

← 一覧ページへ戻る

1. GitHub トークンの設定

このページはあなたのブラウザから GitHub API を直接呼び出して、リポジトリにコミットします。 Fine-grained personal access token（対象リポジトリのみ・Contents: Read and write 権限のみ）を発行して入力してください。 トークンはこの端末のブラウザ内（localStorage）にのみ保存され、他の場所には送信されません。 共有パソコンでは「保存」せず、使い終わったら「削除」してください。

2. 新しい資料を登録

Google Drive のリンクは「リンクを知っている全員が閲覧可」の共有設定にしてください。サイト上で資料・動画をその場でプレビュー表示できます。
